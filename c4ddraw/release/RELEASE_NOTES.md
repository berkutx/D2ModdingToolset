В C4dll-R __VER__ добавлен Twitch Stat: зрители трансляции могут наводить курсор на отряды в бою и читать их параметры и способности.

- В архиве `__ZIP__` находятся врапер, `Mods/timer.c4p` и `Mods/twitchstat.c4p`. Twitch Stat сам запускает встроенное локальное соединение при включении плагина; установка Node.js и отдельный запуск моста не нужны.
- Соединение доступно только на `127.0.0.1:8765` и передаёт данные своего игрового процесса. При выключении плагина оно закрывается. Если порт занят другим клиентом, плагин сообщает об этом в меню; автоматического переключения между играми нет.
- Для новой установки Twitch Stat включён по умолчанию: `[TwitchStat] Enabled=1`, `Preview=0`, `Profile=0`. Явные значения существующего конфига сохраняются. Включение локального плагина само по себе не запускает трансляцию и не публикует данные на Twitch.
- Оверлей показывает полупрозрачную карточку с параметрами отряда при наведении. Захват использует штатные данные игры, сохраняет проверки состояния боя и обновляет зрителям только завершённые снимки.
- Исправлено ожидание первого снимка при уже открытом локальном выборе действия: прежний флаг анимации мог оставаться выставленным до первой атаки. Подтверждённый открытый выбор теперь учитывается отдельно; неизвестное состояние и проигрывание действия по-прежнему не разрешают захват.

Расширение **Disciples II Battle Info** устанавливается и активируется на Twitch отдельно. Пока оно находится в **Hosted Test**, необходим доступ тестера; общедоступная установка появится после проверки Twitch и выпуска расширения. Для передачи данных во время эфира откройте его Live Configuration, нажмите «Подключить игру» и оставьте панель и окно соединения открытыми. Пошаговая инструкция находится в архиве (`TWITCH-STREAMER-RU.md`) и [доступна онлайн](https://github.com/berkutx/D2ModdingToolset/blob/c4dll-r-v2.0/twitch-extension/STREAMER-RU.md).

Поддерживается совместимый боевой интерфейс Russobit/MNS. В OBS показывайте игровое изображение целиком, без обрезки и смещения; дополнительные варианты масштабирования требуют отдельной проверки. Зрителям ничего устанавливать на компьютер не нужно.

Перед обновлением закройте все клиенты игры. Обновите `C4dll-R.dll`, `Mods/timer.c4p` и `Mods/twitchstat.c4p` из одного архива. Сохраните свои `ddraw.ini`, `C4menu.ini` и `C4plugins.ini`; сброс настроек не требуется. Существующий `Enabled=0` можно изменить через `Plugins > Twitch Stat > Enabled`.

Сохранены исправления палитры, завершения хода и отмены перетаскивания перед действием таймера из ветки 1.9.x. Переключатель краевой прокрутки и настройки MNS/SMNS остаются в «Игра > MNS/SMNS». Мигание таймера настраивается за 10–45 секунд с шагом 5 секунд, по умолчанию — 20 секунд; мягкий звуковой сигнал по умолчанию выключен. Поведение Set не менялось.
