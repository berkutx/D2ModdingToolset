**C4dll-R __VER__**

Версия 1.7 исправляет миграцию настроек старого враппера: профиль с
`DisplayWidth` / `DisplayHeight`, но без `GameCanvasMode`, сохраняется как штатный,
поэтому фиксированный вывод 4:3 больше не соединяется самопроизвольно с Hor+ и не
создаёт симметричные чёрные полосы. Явно выбранные режимы Hor+ и Auto не меняются.
Старый вывод меньше логического кадра больше не поддерживается: сохранённая пара
вроде `800x600` поверх игры `1024x768` переводится в `0x0` (следовать игре), поэтому
внутренний экран `800x600` не превращается в искусственные `625x469`.

Исправлен боевой фон при выключенном WideBattle: на штатном 800x600 зеркальная
перспектива больше не получает постоянный чёрный участок шириной 150 пикселей.
Восстановлена оригинальная mirror-aware формула DisciplesGL, а расширенный диалог
теперь включается по эффективной fixed-screen ширине с учётом `EnableZoom` и
`ZoomFactor`. Поэтому штатные 1024x768/1280x1024 с обычным zoom остаются 800-wide,
а проверенные Hor+ разрешения выбирают 990-wide.

«Видео -> Разрешение» теперь показывает один прямой список всех разрешений игры:
`★` отмечает штатные 800x600, 1024x768 и 1280x1024, остальные пункты — проверенные
Hor+. Отдельный «Доп. вывод» удалён из игрового меню; старые или вручную заданные
`ddraw.ini width` / `height` продолжают читаться только для совместимости, а явный
выбор разрешения возвращает их в `0x0`. Auto сообщает только `сейчас -> после
перезапуска`, без теоретической доступной области и коэффициента.

Штатные режимы 1024x768 и 1280x1024 не растягивают фиксированные меню 800x600:
игра центрирует их и рисует собственный `GrBorder` / `ShowInterfBorder` внутри
логического кадра. Это не поля или масштаб рендерера. Декор Hor+ остаётся отдельным
слоем враппера.

Синтетическая фиксация курсора в центре удалена. В активной и неактивной клиентской
области используется один игровой меч в реальной позиции мыши; меню и заголовок
используют одну системную стрелку. Окно таймера больше не переводит HOST в
topmost-band, а фоновый edge-scroll MNS блокируется без подмены координат.

Декоративный фон и рамка теперь всегда включены на проверенном широком layout;
пункт меню удалён, а старый `decorativeBackground=0` игнорируется и удаляется из
`C4menu.ini`. Автоподтверждение найма включено по умолчанию только для проверенного
Russobit/MNS exe; его явные значения в существующем `C4menu.ini` сохраняются.
Пункт облаков называется «Показывать облака» и остаётся в меню «Игра»: отсутствие
штатного `[Settings] IsoBirds` означает «включено», явный `IsoBirds=0` остаётся
выключенным. Для отображения по-прежнему нужен проверенный внешний `IsoClouds.ff`.

Рендерер OpenGL / GDI / Auto теперь меняется без перезапуска; меню отдельно показывает
сохранённый выбор и фактический backend после runtime-проверки. Lanczos, Bicubic, Bilinear и «Без
фильтра» работают также в Auto/D3D9; GDI получает сглаженный/nearest fallback. Неполный
локальный Mesa-загрузчик больше не блокирует системный OpenGL.

В PvP личный таймер всегда идёт на принятом выборе локального игрока и никогда не
идёт на выборе или проигрывании соперника. Собственное проигрывание удара учитывается
только при выключенном `Animation Pause`; включённая опция исключает даже долгую
медленную анимацию из времени на раздумья. Обязательный выбор цели второй атаки —
новый полноценный интервал выбора и тоже расходует банк.
При истечении он фиксируется на `00:00` и включает штатный Auto Battle для своей
стороны без возможности отмены до завершения боя. `Combat Pause` сохраняет
приоритет, а End Day после боя выполняется только для текущего локального
стратегического игрока.

Скачайте `__ZIP__`; инструкция находится в `INSTALL.txt`.
