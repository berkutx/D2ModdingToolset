В версии __VER__ добавлена штатная отмена перетаскивания при истечении таймера:

- Перед принудительным завершением хода, закрытием внутриигрового диалога или включением автобоя таймер отменяет активное перетаскивание через механизм игры. Это устраняет ситуацию, когда объект переноса уже удалён, а курсор продолжает обращаться к нему.
- После отмены запрос таймера сохраняется, а состояние игрового окна проверяется заново перед продолжением. Отмена перетаскивания не восстанавливает истёкшее время.

Обновите C4dll-R.dll и Mods/timer.c4p из архива вместе, предварительно закрыв все клиенты игры. При обновлении сохраните свои ddraw.ini, C4menu.ini и C4plugins.ini.

Исправления палитры и обработки завершения хода из 1.9.3 сохранены. Настройки предупреждения прежние: мигание за 10–45 секунд с шагом 5 секунд (по умолчанию 20 секунд), мягкий звуковой сигнал по умолчанию выключен. Отсутствующие параметры получают значения по умолчанию. Поведение Set не менялось.

Опасный порядок удаления объекта подтверждён на штатном коде игры в изолированной проверке. Полный сетевой игровой прогон этой версии пока не выполнен.
