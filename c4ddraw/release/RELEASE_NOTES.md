В версии __VER__ исправлены белые пятна у городов и обработка истечения таймера:

- Сохранены все цвета палитры игровых текстур, включая №255. Прозрачные эффекты больше не превращаются в белые квадраты при заходе в город или его захвате.
- Запрос завершения хода сохраняется, пока игра обрабатывает команды. Это исправляет потерю пропуска после закрытия гарнизона и при начале хода с уже отрицательным банком.
- Послебоевой учёт времени завершается при возврате на стратегическую карту, чтобы таймер правильно распознавал следующие ходы после PvE.

Обновите C4dll-R.dll и Mods/timer.c4p из архива вместе, предварительно закрыв все клиенты игры. При обновлении сохраните свои ddraw.ini, C4menu.ini и C4plugins.ini.

Настройки предупреждения из 1.9.2 сохранены: мигание за 10–45 секунд с шагом 5 секунд (по умолчанию 20 секунд), мягкий звуковой сигнал по умолчанию выключен. Отсутствующие параметры получают значения по умолчанию. Поведение Set не менялось.

Причины проверены по дампам и воспроизведению. В сборке выполняются 10 проверок палитры, 23 проверки завершения хода и 26 проверок плагина. Полный сетевой игровой прогон этой версии пока не выполнен.
