================================================================================
 C4dll-R  -  self-contained DirectDraw wrapper for Disciples II
================================================================================

WHAT THIS IS
  C4dll-R.dll embeds cnc-ddraw in one drop-in DirectDraw wrapper.
  Included plugins: Mods\timer.c4p is the reconstructed turn timer;
  Mods\twitchstat.c4p snapshots all 12 battle slots for Twitch on left click without
  bundling unit art or a duplicate database.

REQUIREMENTS
  - Disciples II. Renderer, video/performance menu, language and locale work on
    other builds too. Game resolution and Widescreen Battle recognize the nine
    original game layouts (D2 2.00-3.01). Remaining exact-address options are
    labelled (MNS/SMNS) and disabled elsewhere; MNS/SMNS means the validated
    4,187,648-byte and 4,214,272-byte Discipl2.exe layouts.
  - The game's existing CB63.dll, Mss23.dll and mss32.dll stay as they are.

INSTALL
  1. Make a backup of your current C4dll-R.dll (if you have one).
  2. Copy C4dll-R.dll next to Discipl2.exe (replace the existing one).
  3. Copy ddraw.ini next to Discipl2.exe - these are the recommended renderer
     defaults (windowed with the menu bar, OpenGL, game speed cap 180).
     Upgrading and already tuned your ddraw.ini? Keep yours.
  4. Copy the Shaders\ folder next to Discipl2.exe. It contains the exact eight
     OpenGL filters shown by the Video menu, including required multipass files.
  5. If upgrading from Unit Info, delete the exact old Mods\unitinfo.c4p first.
     Then copy Mods\timer.c4p and Mods\twitchstat.c4p into the game's Mods\ folder.
     Always update C4dll-R.dll and timer.c4p together; safe tournament Auto Battle needs both.
  6. (Optional) Copy C4plugins.ini next to Discipl2.exe to configure both plugins.
     C4PLUGINS.txt explains every key and which changes apply live or need a restart.
  7. (Optional) Keep an existing Imgs\IsoClouds.ff from a DisciplesGL install
     if you want to use Game > Show map clouds. The archive is not redistributed
     in this package. The required 30393-byte file has SHA-256:
     962F334E1CFA3226AF27B953AF0F6EBA6C1F82EF708A948C0D4C2A76FF804EE6
     If it is absent or its exact hash differs, clouds cannot be enabled. An
     already-requested invalid setting remains clickable only so it can be
     switched OFF. If [Settings] IsoBirds is absent, the native default is ON;
     an explicit IsoBirds=0 remains OFF. A change requires a full game restart.
  8. If the game folder contains a standalone ddraw.dll from another wrapper,
     rename or remove it. A clean installation normally has no such file; if it
     is absent, do nothing.
  9. Launch the game.

  Note: without ddraw.ini the renderer generates its tuned first-run config:
  a bordered window with the menu, OpenGL, a normal window following the selected
  game resolution, and game speed cap 180. The bundled ddraw.ini additionally enables
  resizing and remembers window size/position, so copying it remains the intended setup.

USING IT
  - See RELEASE_NOTES.md for this exact package's changes and known limitations.
    Bounded message batching is ON by default on the validated executable. It
    accelerates command delivery without raising the configured 180-tick cap.
    To disable it, set messageBatching=0 in the existing [menu] section of
    C4menu.ini and restart the game. See MESSAGE_BATCHING.md for details.
    Network tracing is optional and OFF by default. Performance > Network/timing
    diagnostics (restart)... asks for confirmation, saves netTrace and immediately
    closes this client. Launch it again manually to apply the setting. Save first:
    unsaved progress can be lost and a network session will disconnect. There is
    no automatic save or relaunch. C4DLL_NETTRACE=1 forces tracing ON; the menu
    explains this override and cannot turn it OFF until that environment setting
    is removed before the next launch. NETWORK_TRACE.md covers capture and limits.
    Tracing is not required for batching and is not a freeze-recovery mechanism.
  - Missing filter settings now default to Lanczos; an existing explicit choice
    is preserved until you change it or reset the wrapper. Game > Reset wrapper
    settings... asks for confirmation and restores video/scaling, performance,
    animation multipliers and convenience defaults. Timer/plugin settings and
    native gameplay settings are preserved. After successfully saving the reset,
    the client closes immediately; all defaults apply on your next manual launch.
    It does not half-apply settings live. Save first: unsaved progress can be lost
    and a network session will disconnect. No automatic save or relaunch occurs.
  - General Win32 message/timing tracing does not depend on a mod version. Detailed
    game-queue observers require the recognized EXE hash and unchanged hook-site
    signatures. A modified prologue is skipped, not followed into another DLL.
    Diagnostics do not use mss32.dll-relative addresses; missing hooks mean less
    coverage, not proof that a network message was lost.
  - In-game menu (under the title bar): Game / Video / Performance / Plugins.
    Renderer, shader, windowed/fullscreen etc. are in Video / Performance.
    The current wrapper has three output modes: normal window, adaptive
    borderless fullscreen and true exclusive fullscreen. This is not a 1:1
    copy of the old adapter's fullscreen path. The menu bar is intentionally
    hidden in both fullscreen modes. F4 switches either one back to a normal
    window (and returns to the last fullscreen kind); Alt+Enter is also
    available. Destination menu chrome is staged before the renderer mode-set,
    so no default-sized intermediate frame is drawn; a redundant relayout is
    used only if the resulting chrome needs recovery.
  - On a validated widescreen game resolution, the decorative background/frame
    around fixed-size screens is always active and has no menu switch. An obsolete
    decorativeBackground value in C4menu.ini is ignored and removed on startup.
  - Game > (MNS/SMNS) Auto-confirm unit hire is ON by default only for the
    signature-validated Russobit/MNS executable. Explicit settings in an existing
    C4menu.ini remain authoritative.
  - If the game randomly crashes or freezes on any map, enable
    Performance > 1 CPU stability (restart). It is ON by default; changing it
    requires a full game restart.
  - Entries labelled (MNS/SMNS) are exact-address gameplay options: Battle animation and Map animation
     (live x1.5..x5 speed-up),
     map drag-scroll (ON by default; exact button-down anchor, movement starts on
     the first changed game pixel; native edge-scroll remains available and follows
     the game's Fast/Normal/Slow setting live through the resolution-scaled
     DisciplesGL cadence, while held-button drag remains 1:1),
     plus Battle speed / Map turn speed (engine presets, saved per game) and
     restart-only Show map clouds (the game's native option; requires external IsoClouds.ff).
  - Video > Resolution is one direct list. Auto is first; all 13 manual game
    resolutions follow in the same list. `★` marks the three native modes
    (800x600, 1024x768 and 1280x1024); the other ten are validated Hor+ canvases
    from 1066x600 through 2560x1440. Auto selects the largest fitting canvas.
    Its status and restart notice show only the current and after-restart sizes,
    not a theoretical available area or scale. Every choice returns normal output
    to follow the game canvas and needs a full restart.
  - Native 1024x768 and 1280x1024 do not stretch fixed 800x600 menus. The game
    centres them and draws its own GrBorder/ShowInterfBorder surround inside the
    game canvas. Hor+ decoration is a separate wrapper-owned compositor.
  - Video > Scaling offers Fit and Integer and shows the actual
    output, coefficient, viewport and bars. `1:1` means one game pixel equals one
    output pixel. A normal window cannot be smaller than the logical game canvas;
    stale undersized width/height pairs are repaired to `0x0` (follow the game).
    Borderless fullscreen always adapts to the desktop. Normal, borderless and
    exclusive output use this common base geometry and the same fixed-screen
    source crop; the output mode changes the target, not the crop.
  - Video > Fixed window ports DisciplesGL 1.90's centred crop. At its default
    full-height setting, 1366x768 enlarges the exact 1068x600 crop to the viewport: the
    fixed 800x600 screen becomes 1024x768 (128% size), side background is cropped,
    and filtering loses some quality. The menu shows actual size, where 100% means
    no enlargement; the compatible C4menu.ini stretchWindows=0..100 value remains
    an internal legacy effect strength. Changes apply live. As in the old adapter,
    it activates only on
    fixed/decorated screens; the strategic map remains unzoomed. Ctrl+Wheel
    remains an additional live zoom.
  - OpenGL processes a fixed screen in the legacy order: centred active crop,
    selected filter/upscaler, final viewport. FSR and xBRZ keep both passes;
    active-crop uniforms and edge clamps prevent the larger POT framebuffer's
    unwritten right/bottom padding from entering the image. True 1:1 bypasses
    upscale-only presets, while an actual reduction uses linear sampling.
  - On native Windows, dragging a normal resizable OpenGL window previews the
    last texture using its active single-pass filter. Releasing the edge commits the final filter once, not
    a game restart. D3D9/GDI, an active multipass FSR/xBRZ pipeline, Wine/macOS
    and child-window cases use the frozen preview and rebuild once on release.
  - Video > Resolution > Window/output size changes only the renderer target and
    applies live; it never adds map view. Automatic follows the logical game
    canvas. A game-resolution choice resets it to Automatic, and borderless still
    follows the desktop.
  - `fake_mode=1024x768x16` is only an internal virtual 16-bit compatibility
    bootstrap. It is not the game resolution, output size or scaling mode; the
    widescreen startup fix adjusts process-local geometry without rewriting it.
  - Widescreen Battle is automatic and ON by default on a recognized original
    layout; there is no menu switch in this release. It selects a fixed 990-wide
    battle layout and shows both unit panels when both the logical canvas and
    effective fixed-screen view are at least 990 pixels wide. Thus default
    1024x768/1280x1024 zoom stays 800-wide, while Hor+ is 990-wide; it does not
    select or replace the game resolution. Windowed, borderless and exclusive
    modes use the same predicate; output mode and physical output size are not inputs.
  - Twitch Stat is ON by default. On the exact Russobit/MNS executable with the
    990-wide battle dialog active, left-click an occupied unit image. One click snapshots
     all 12 visual slots, logical game resolution, battle/slot bounds and the
     visible encyclopedia text of each unique displayed unit as the versioned
     c4dll.battle-roster / battle.snapshot payload. A large portrait uses the game's
     continuous native 150x85 hit area, including the seam between its two logical slots.
     The diagnostic preview is OFF by default. The host sends Twitch Stat no draw/tick/input callbacks outside battle.
     If the player's native right-click encyclopedia is already open, Twitch Stat neither creates a second
     layout nor consumes the click; it resumes after close. A successful snapshot consumes only that
     LMB down/up gesture so it cannot also activate a battle command. Toggle it at Plugins >
    Twitch Stat > Enabled or in C4plugins.ini [TwitchStat]. It has no unit art/database
    and no mss32.dll import.
  - The turn timer is configured in C4plugins.ini, section [Timer]; see the included
    C4PLUGINS.txt for all keys and live/restart behaviour. The bundled
    PvP defaults use a 5-minute Force countdown, pause for battle animations and
    player-vs-player combat, then end the turn without retreat. With Combat Pause
    off, an accepted local choice is always billed; opponent phases are never billed.
    Outside PvP, billable time can pass zero during combat and reward/artifact dialogs.
    That signed overtime becomes debt against the same player's next budget. End Day
    is queued once, but the host does not choose a reward: after battle resolution it
    waits for the real strategic screen and submits the final networked click once.
    PvP instead clamps and freezes at 00:00. AutoBattle is ON by default for tournaments:
    the timer invokes the game's own TOG_AUTOBATTLE callback for that battle instance
    and side. Until that battle ends, click, hotkey and a manual battle action cannot
    remove or bypass the latch; chat and unrelated mouse/keyboard input remain usable.
    Local attack playback is billed only when Animation Pause is off. Mandatory
    second-target selection is a new billed choice. Hold Ctrl+Alt
    and drag the clock with LMB to reposition it. On the exact Russobit/MNS
    layout the countdown starts only after you accept the normal begin-turn
    summary with OK; time does not run under that dialog. Pause, Reset and Set
    update a running Force clock immediately. Every pause makes the timer white;
    only an explicit user Pause adds "(пауза)". Other executable
    layouts keep the active-turn-edge fallback.

UNINSTALL / REVERT
  - Restore your backed-up C4dll-R.dll and remove Mods\timer.c4p and
    Mods\twitchstat.c4p (and legacy Mods\unitinfo.c4p, if present).

================================================================================
 C4dll-R  -  самодостаточный DirectDraw-врапер для Disciples II
================================================================================

ЧТО ЭТО
  C4dll-R.dll встраивает cnc-ddraw в одну подключаемую DirectDraw-DLL.
  В комплекте два плагина: Mods\timer.c4p — воссозданный таймер хода;
  Mods\twitchstat.c4p — источник снимка всех 12 боевых слотов для Twitch без
  собственной базы или картинок.

ТРЕБОВАНИЯ
  - Disciples II. Рендерер, меню видео/производительности, язык и локаль работают
    и на других сборках. Разрешение игры и «Широкий бой» распознают девять
    исходных игровых layout’ов D2 2.00–3.01. Остальные точные адресные опции
    помечены (MNS/SMNS) и заблокированы на других exe; MNS/SMNS означает две
    проверенные раскладки Discipl2.exe размером 4 187 648 и 4 214 272 байта.
  - Имеющиеся CB63.dll, Mss23.dll и mss32.dll игры остаются как есть.

УСТАНОВКА
  1. Сделайте резервную копию текущего C4dll-R.dll (если он есть).
  2. Скопируйте C4dll-R.dll рядом с Discipl2.exe (заменив существующий).
  3. Скопируйте ddraw.ini рядом с Discipl2.exe - это рекомендованные настройки
     рендерера (окно с меню-баром, OpenGL, кап скорости игры 180).
     Обновляетесь и уже настроили свой ddraw.ini? Оставьте свой.
  4. Скопируйте папку Shaders\ рядом с Discipl2.exe. В ней находятся ровно восемь
     OpenGL-фильтров из меню Video и необходимые файлы multipass.
  5. При обновлении с Unit Info сначала удалите именно старый Mods\unitinfo.c4p.
     Затем скопируйте Mods\timer.c4p и Mods\twitchstat.c4p в папку Mods\ игры.
     C4dll-R.dll и timer.c4p всегда обновляйте вместе: безопасному турнирному
     автобою нужны обе актуальные части.
  6. (Необязательно) Скопируйте C4plugins.ini рядом с Discipl2.exe для настройки
     обоих плагинов. Все ключи и различие между живыми изменениями и рестартом
     описаны в C4PLUGINS.txt.
  7. (Необязательно) Сохраните имеющийся Imgs\IsoClouds.ff от установки
     DisciplesGL, если хотите использовать «Игра > Показывать облака». Этот архив не
     распространяется в комплекте. SHA-256 нужного файла размером 30393 байта:
     962F334E1CFA3226AF27B953AF0F6EBA6C1F82EF708A948C0D4C2A76FF804EE6
     Если файла нет или точный хеш отличается, включить облака нельзя. Уже
     запрошенная ошибочная настройка остаётся доступной только для выключения.
     Если [Settings] IsoBirds отсутствует, штатное значение по умолчанию — включено;
     явный IsoBirds=0 остаётся выключенным. Смена требует полного перезапуска игры.
  8. Если в папке игры есть отдельный ddraw.dll от другого врапера, переименуйте
     или удалите его. В чистой установке такого файла обычно нет; если его нет,
     ничего делать не нужно.
  9. Запустите игру.

  Примечание: без ddraw.ini рендерер при первом запуске создаст свой настроенный
  конфиг: окно с рамкой и меню, OpenGL, обычное окно следует выбранному разрешению
  игры, кап скорости игры — 180. Комплектный ddraw.ini дополнительно
  разрешает менять размер окна и запоминает его размер/позицию, поэтому его
  копирование остаётся задуманным вариантом.

КАК ПОЛЬЗОВАТЬСЯ
  - Изменения и известные ограничения именно этого пакета — в RELEASE_NOTES.md.
    Обработка ограниченных пачек сообщений включена по умолчанию на проверенном
    exe. Она ускоряет доставку команд без повышения настройки 180 тиков.
    Для отключения задайте messageBatching=0 в существующей секции [menu]
    файла C4menu.ini и перезапустите игру. Подробности — в MESSAGE_BATCHING.md.
    Трассировка необязательна и по умолчанию выключена. «Производительность >
    Диагностика сети и задержек (рестарт)...» после подтверждения сохраняет netTrace
    и сразу закрывает этот клиент. Для применения запустите его снова вручную.
    Сначала сохраните игру: несохранённый прогресс может пропасть, сетевое подключение
    прервётся. Автосохранения и автозапуска нет. C4DLL_NETTRACE=1 принудительно включает
    трассу; меню показывает эту причину и не позволяет выключить её, пока переменная
    не убрана перед следующим запуском. Сбор логов и лимиты — в NETWORK_TRACE.md.
    Для пачек трасса не нужна и средством разблокировки зависания не является.
  - Без ключа фильтра используется Lanczos; существующий явный выбор сохраняется
    до его смены или сброса. «Игра > Сбросить настройки враппера...» после
    подтверждения возвращает стандартные видео/масштаб, производительность,
    множители анимаций и удобства. Настройки таймера, плагинов и штатные игровые
    параметры сохраняются. После успешной записи сброса клиент сразу закрывается;
    все значения применяются при следующем ручном запуске, не частично на лету.
    Сначала сохраните игру: несохранённый прогресс может пропасть, сетевое подключение
    прервётся. Автосохранения и автоматического повторного запуска нет.
  - Общая Win32-трасса сообщений/тайминга не зависит от версии мода. Подробные
    наблюдатели игровых очередей требуют проверенного хэша EXE и неизменённых
    сигнатур точек перехвата. Изменённый пролог пропускается: переход в другую DLL
    не прослеживается. Диагностика не использует адреса относительно mss32.dll;
    отсутствие наблюдателя уменьшает покрытие, а не доказывает потерю сообщения.
  - Внутриигровое меню (под заголовком окна): Game / Video / Performance /
    Plugins. Рендерер, шейдер, окно/полный экран - в Video / Performance.
    Текущий враппер имеет три режима вывода: обычное окно, адаптивный
    безрамочный и настоящий эксклюзивный полный экран. Это не копия fullscreen-пути
    старого адаптера 1:1. В обоих полноэкранных режимах меню-бар намеренно скрыт.
    F4 возвращает из них в обычное окно (и обратно в последний вид полного экрана);
    также доступен Alt+Enter. Chrome целевого режима ставится до mode-set рендера,
    поэтому промежуточный кадр стандартного размера не рисуется; повторный relayout
    используется только как восстановление при несовпадении итогового chrome.
  - На проверенном широком разрешении декоративный фон/рамка вокруг фиксированных
    экранов всегда активен и не имеет пункта меню. Устаревшее значение
    decorativeBackground в C4menu.ini игнорируется и удаляется при запуске.
  - «Игра > (MNS/SMNS) Автоподтверждение найма» включено по умолчанию только
    для exe Russobit/MNS с совпавшими сигнатурами. Явные значения существующего
    C4menu.ini сохраняются.
  - Если игра случайно вылетает или зависает на любой карте, включите
    Производительность > 1 CPU: стабильность (рестарт). По умолчанию режим уже
    включён; после изменения полностью перезапустите игру.
  - Пункты с пометкой (MNS/SMNS) — точные адресные игровые опции: Battle animation и Map animation
     (живое ускорение x1.5..x5),
     перетаскивание карты (включено по умолчанию; точка нажатия сохраняется без
     стартового рывка; штатный краевой скролл остаётся и сразу следует игровой
     настройке Быстро/Нормально/Медленно через масштабируемый по разрешению такт
     DisciplesGL 100%/75%/50%, а drag остаётся 1:1), а также Battle speed / Map turn speed (пресеты движка,
     хранятся в сейве), и restart-only «Показывать облака» (штатная опция игры;
     нужен внешний IsoClouds.ff).
  - Видео > Разрешение — один прямой список. Сначала идёт «Авто», затем все 13
     ручных разрешений игры. `★` отмечает три штатных режима (800x600, 1024x768 и
     1280x1024), остальные десять — проверенные Hor+ от 1066x600 до 2560x1440.
     Авто выбирает самый крупный помещающийся кадр. Его строка и сообщение о
     перезапуске показывают только текущий и будущий размеры, без теоретической
     доступной области и коэффициента. Каждый выбор снова привязывает вывод к
     игровому кадру и требует полного перезапуска.
  - Штатные 1024x768 и 1280x1024 не растягивают фиксированные меню 800x600. Игра
     центрирует их и рисует собственный GrBorder/ShowInterfBorder внутри игрового
     кадра. Декор Hor+ — отдельный композитор враппера.
  - Видео > Масштаб содержит «Вписать» и «Целые» и показывает
     фактический вывод, коэффициент, viewport и поля. `1:1` означает один игровой
     пиксель на один выходной. Обычное окно не может быть меньше логического кадра;
     старые меньшие width/height исправляются на `0x0` (следовать игре). Безрамочный
     полный экран всегда адаптируется к рабочему столу. Обычное окно, borderless и
     exclusive используют эту общую базовую геометрию и один fixed-screen source
     crop: режим вывода меняет цель, но не сам crop.
  - Видео > Центральное окно переносит центрированный crop из DisciplesGL 1.90.
     В максимальном режиме по умолчанию для 1366x768 точный crop 1068x600 увеличивается
     до viewport: фиксированные 800x600 становятся 1024x768 (128% размера), боковой
     фон обрезается, фильтрация ожидаемо снижает качество. GUI показывает фактический
     размер, где 100% означает отсутствие увеличения. Совместимый ключ C4menu.ini
     stretchWindows=0..100 остаётся внутренней силой старого эффекта. Выбор применяется
     сразу. Как в старом адаптере, это
     действует только в фиксированных/декорированных окнах; карта не приближается.
     Ctrl+колесо остаётся добавочным zoom.
  - OpenGL обрабатывает фиксированный экран в порядке старого адаптера:
     центрированный активный crop, выбранный фильтр/upscaler, финальный viewport.
     FSR и xBRZ сохраняют оба прохода; отдельные размеры активного crop и POT-FBO
     вместе с edge clamp не дают неинициализированному padding справа/снизу попасть
     в изображение. Настоящий 1:1 пропускает upscale-only пресет, а реальное
     уменьшение использует linear sampling.
  - На обычном Windows край изменяемого OpenGL-окна масштабирует последний кадр
     активным однопроходным фильтром.
     После отпускания окончательный фильтр фиксируется одним commit, а не
     перезапуском игры. D3D9/GDI, активный многопроходный FSR/xBRZ, Wine/macOS и
     дочерние окна сохраняют замороженный preview и одну пересборку после отпускания.
  - Видео > Разрешение > Размер окна/вывода меняет только цель рендера и
     применяется сразу, не добавляя обзор карты. «Автоматически» следует
     логическому кадру игры. Выбор разрешения игры возвращает этот размер в
     «Авто», а безрамочный режим по-прежнему берёт рабочий стол.
  - `fake_mode=1024x768x16` — только внутренний виртуальный 16-битный bootstrap
     совместимости. Это не разрешение игры, вывод или режим масштаба; исправление
     широкого запуска меняет process-local геометрию без перезаписи значения.
  - «Широкий бой» включается автоматически и по умолчанию на распознанной
     исходной раскладке; отдельного пункта меню в этом релизе нет. Он выбирает
     фиксированную боевую раскладку шириной 990 и показывает обе панели при
     логическом кадре и эффективном фиксированном виде не уже 990. Поэтому
     штатные 1024x768/1280x1024 с обычным zoom остаются 800-wide, а Hor+ —
     990-wide; само разрешение игры этот режим не выбирает и не заменяет. Условие
     одинаково для окна, borderless и exclusive; режим и физический размер вывода
     в него не входят.
  - Twitch Stat включён по умолчанию. На точном exe Russobit/MNS при активном
    боевом диалоге шириной 990 нажмите ЛКМ по занятому изображению отряда. Один клик собирает
     все 12 видимых слотов, логическое разрешение, границы боя/портретов и видимый
     текст энциклопедии каждого уникального отряда в payload c4dll.battle-roster /
     battle.snapshot. Для большого портрета используется непрерывная штатная hit-area
     150x85, включая шов между двумя логическими слотами. Диагностическое окно по умолчанию отключено. Вне боя host не
     вызывает draw/tick/input этого плагина. Если штатная энциклопедия по ПКМ уже открыта, второй layout не
     создаётся и ЛКМ остаётся игре; после закрытия работа возобновляется. Успешный снимок поглощает
     только этот жест ЛКМ down/up, чтобы он не активировал боевую команду. Плагин не
    содержит картинок/базы и не импортирует mss32.dll. Переключатель находится в
    «Плагины > Twitch Stat > Enabled» и в секции [TwitchStat] файла C4plugins.ini.
  - Таймер хода настраивается в C4plugins.ini, секция [Timer]; все ключи и режим
    применения описаны в C4PLUGINS.txt. Комплектные PvP-настройки включают
    принудительный отсчёт 5 минут, паузу на анимациях и в бою
    игрок-против-игрока, затем завершают ход без retreat. При выключенном Combat Pause
    принятый локальный выбор всегда расходует банк, чужие фазы — никогда.
    Вне PvP учитываемое время может уйти в минус во время боя и диалогов
    награды/артефактов. Подписанный перерасход становится долгом этого игрока на
    следующий ход. End Day ставится в очередь один раз, но host не выбирает награду:
    после разрешения боя он ждёт настоящий стратегический экран и лишь затем один раз
    отправляет сетевое завершение хода. В PvP часы вместо этого фиксируются на 00:00.
    AutoBattle по умолчанию включён для турниров и вызывает штатный TOG_AUTOBATTLE
    именно для текущего экземпляра боя и текущей стороны. До конца боя latch нельзя снять или
    обойти кликом, горячей клавишей либо ручным боевым действием; чат и несвязанный
    ввод мыши/клавиатуры остаются доступны.
    Собственная анимация учитывается только при выключенном Animation Pause, а обязательная вторая
    цель открывает новый оплачиваемый выбор. Для перемещения часов
    зажмите Ctrl+Alt и перетащите их ЛКМ. На точной Russobit/MNS-раскладке
    отсчёт начинается только после штатного OK в сводке начала хода: под диалогом
    время не уходит. Pause, Reset и Set сразу обновляют запущенный Force-таймер. При
    любой паузе часы белые; «(пауза)» появляется только после явной команды игрока.
    На других exe сохраняется прежний сигнал активного хода.
