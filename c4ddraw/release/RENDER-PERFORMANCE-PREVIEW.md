# C4dll-R __VER__ — потенциальное исправление лагов сетки Z

Предварительный релиз для проверки сильного замедления игры и курсора при включении сетки Z. Исправлен медленный участок копирования её изображений; устранение всей наблюдаемой проблемы на компьютере джойнера пока не подтверждено.

Включены два ускорения:

- Копирование 16-битных изображений с прозрачным цветом, в том числе сетки Z. В версиях 2.2 и 2.3 этого ускорения ещё нет.
- Полупрозрачное смешивание, сложение и вычитание цветов RGB565. Сохраняется нативное округление. Эти функции включаются только после проверки поддержанного кода игры; для остальных случаев остаётся исходная реализация. Сама сетка использует первое ускорение.

Функции сетки и изображения остаются в MSS/игре. Обновление MSS для этой проверки не требуется.

Сборка Win32 и автоматические проверки пройдены: копирование с прозрачным цветом, совпадение смешивания с игровыми функциями, границы буферов и безопасный отказ при неподдерживаемой версии игры. Это не замер FPS в живом матче.

## Установка

1. Сохранить игру, закончить сетевой матч и полностью закрыть клиент.
2. Сохранить отдельно прежние `C4dll-R.dll`, `Mods/timer.c4p` и `Mods/twitchstat.c4p` для возврата.
3. Из `__ZIP__` заменить `C4dll-R.dll`, оба плагина в `Mods` и файлы `Shaders`. Свои `ddraw.ini`, `C4menu.ini` и `C4plugins.ini` сохранить.
4. Запустить игру обычным способом. Настройки сбрасывать не нужно.

## Проверка

На компьютере, где возникал лаг, открыть ту же карту и позицию, переключить панель на проценты владения землёй. Сравнить прокрутку и реакцию интерфейса в последовательности **Z выключено → включено → выключено**, сохранив остальные настройки.

При сравнении двух компьютеров использовать одну версию DLL, одинаковые разрешение игры, рендерер и настройки эффектов. Записать, сохраняется ли торможение с сеткой. Скорость отдельных функций в тесте не равна приросту FPS всей игры.

Для возврата закрыть игру и вернуть сохранённые DLL/плагины. Инструкция по окну находится в `WINDOW-WORKAREA-RU.txt`, по захвату OBS — в `TWITCH-STREAMER-RU.md`.
