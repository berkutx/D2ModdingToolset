# Область проверки штатного выбора хоста

Пользователь разрешил подготовленные матчи: после согласия хоста создать обычную
генерацию, выбрать ему согласованную расу и необязательный тип лорда с корректным
портретом. Исследуется только локальный Disciples II Russobit x86 и исходники MSS.

Сеть, авторизация и обход ограничений не входят в исследование. EXE не патчится,
игра не запускается, DLL не устанавливается. Права других аккаунтов не меняются.
Изменения MSS относятся к отдельной ветке prepared-matches, не к PR7.

Сначала использованы существующие API и отчёты; затем read-only дизассемблирование
узких адресных диапазонов штатных функций. Наблюдения относятся только к SHA256
`1375cdef09ec470ee64fe5693fb734d7c69fb215212311d997f792b258a642eb`.
