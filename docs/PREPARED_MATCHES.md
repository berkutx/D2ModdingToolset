# Подготовленные матчи: клиент MSS

Клиент принимает адресованное хосту предложение только от аутентифицированного
лобби. Нового capability нет: сообщение добавлено в конец расширений (`ID_USER_PACKET_ENUM + 16`),
старые клиенты его игнорируют. Штатные ручное создание, загрузка и `111` сохраняются.

## Согласие и генерация

Предложение ждёт свободного `CMenuCustomLobby`: без игровой сессии, перехода,
подключения, окна пароля, помощи или другого верхнего интерфейса. Native Yes/No
показывает шаблон, участников, хоста и явно изменённые параметры. Длинные условия
разбиты на страницы по реальным размерам `TXT_INFO` и native метрикам шрифта:
никакое продолжение не отбрасывается. Только последнее «Да» разрешает генерацию.
«Нет» откладывает попытку; повторная доставка той же попытки не открывает окно снова.

После согласия сверяются точные basename и MD5 с неизменяемым каталогом запуска.
Каталог сохраняет исходные байты Lua, hash и разобранные defaults. Hash считается
по binary bytes, включая CRLF. RSG предоставляет только path-reader настроек:
при startup исходник читается до и после этого reader; изменение файла отвергается.
Возврат в меню не перечитывает шаблоны. Добавленный или заменённый Lua требует
перезапуска клиента. Автоматического скачивания и выполнения серверного Lua нет.

Обычный генератор получает проверенные настройки и сохранённый source. Preview,
Retry, Accept и Cancel используют существующий GUI; повторная попытка заново
исполняет `getContents`, не переиспользуя ранее выпавшее содержимое. Это первая
генерация, а не команда рестарта. Accept сохраняет тот же рецепт для последующего `111`.

Согласованная раса хоста становится первой в native списке setup. Тип лорда
переключается существующим callback `BTN_LORD`, с сохранением выбранного портрета
и проверкой AnsStartInfo. Проверены native пути Russobit; для неподтверждённых
версий автоматическая генерация завершается явной ошибкой. Выборы джойнеров
автоматически не меняются. [Доказательство](2026-09-20_reverse-prepared-native-report.md).

## Идентичность и отмена

Каждая попытка имеет preparationId, gameId, attemptId и revision. Все поля строк
имеют bounded length, integers — big-endian, лишние байты и неизвестные параметры
отвергаются. Native race IDs: Empire0, Undead1, Legions2, Clans3, Elves5;
wire random=-1 отдельно переводится в RSG Random. Типы лорда: Mage0, Warrior1, Thief2.

`PreparationId`, `GameId`, `PreparationAttemptId`, `PreparationRevision` передаются
как отдельные room properties. Данные не связываются по сходству никнеймов и времени.

Cancel ставит запрет Accept/CreateRoom на главном потоке. После этой гарантии MSS
отправляет Canceled ACK, не дожидаясь тяжёлой геометрии генератора. До завершения
старого worker и очистки preview новая попытка остаётся в очереди. Если CreateRoom
уже отправлен, MSS ждёт действительного ответа и не прерывает созданную игру;
лобби получает RoomCreated либо ошибку. RoomsPlugin и статусы используют один
RELIABLE_ORDERED channel 0. Modal callback хранит только epoch, не указатель на меню.

## Проверки

- `tests/preparedmatchprotocol_test.cpp`: golden wire/status, truncation каждого
  байта, version/length/trailing bytes, категории, signed custom values и ключи.
- `tests/preparedmatchsettings_test.cpp`: defaults, неизменность snapshot, host-first,
  clans/undead mapping, random, диапазоны и шаги custom spins, число игроков.
- `tests/preparedmatchlifecycle_test.cpp`: cancel ACK до создания, safe-point для
  генерации/CreateRoom, поздняя отмена созданной комнаты и повторная отмена при возврате.
- `tests/run-prepared-match-protocol.ps1`: запускается из MSVC x86 developer shell;
  `OutputDirectory` обязателен, `DependenciesRoot` включает дополнительные RSG settings tests.
- Существующий `run-scenario-template-recipe.ps1` проверяет fresh Lua state и
  входы `getContents`, в том числе реальные локальные Outrunner при указании путей.

Автоматические консольные проверки не заменяют игровой прогон. Перед выпуском
нужны два клиента с `DisplayErrors=1`: занятое меню, Yes/No, длинные условия,
отсутствующий/hash-mismatch Lua, Retry/Cancel, Cancel↔Accept race, native портрет,
вход джойнера, завершение и `111`. Изменять установленную DLL без согласования нельзя.
Короткие шаги и критерии остановки — [ручная приёмка](PREPARED_MATCHES_ACCEPTANCE_RU.md).
